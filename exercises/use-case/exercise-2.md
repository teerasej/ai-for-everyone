# Exercise 2 — Auto Report Writing ด้วย Copilot in Word

## Step 1: เปิดไฟล์และเปิด Copilot

1. เปิดไฟล์ Word `CPALL_Lab_Word_OpsReport_Source.docx`
2. กดปุ่ม Copilot ใน Word (มุมขวาบน หรือแถบ Home ตามเวอร์ชัน)

> ✅ Critical step: ให้ผู้เรียนเห็นแถบ Copilot ด้านขวา/กล่อง prompt ในเอกสาร


## Step 2: ร่างรายงานฉบับแรก

ใช้ Prompt ด้านล่างเพื่อให้ Copilot ร่างรายงานสรุปผู้บริหาร

```
ใช้ข้อมูลในเอกสารนี้ (Raw Notes + Action Draft)
ร่าง "รายงานสรุปผู้บริหาร" ความยาว 1–2 หน้า
โครงต้องมี: Executive summary (5 bullets) / KPI highlights / Issues & root causes / 2-week mitigation plan (owner+due) / Requests to leadership
ภาษาไทย ทางการ กระชับ อ่านง่าย
```

ตรวจงาน: ผลลัพธ์ต้องมีครบทุกหัวข้อ
- Executive summary
- KPI highlights
- Issues & root cause
- 2-week plan
- Requests


## Step 3: ปรับคุณภาพภาษาให้ทางการและกระชับ

```
ปรับรายงานให้เหมาะกับผู้บริหาร:
- ตัดคำฟุ่มเฟือย
- ใช้หัวข้อสั้น ๆ
- ทำให้ข้อเสนอแนะ actionable มากขึ้น
- เพิ่มประโยค "ผลกระทบ" ให้ชัดเจนในแต่ละ issue
```


## Step 4: สร้างตาราง Action Plan

```
สร้างตาราง Action plan โดยมีคอลัมน์: Action | Owner | Due | Expected outcome | Status
ใช้ข้อมูลจากส่วน "รายการ Action ที่ต้องทำ (Draft)" และจัดให้อ่านง่าย
```


## Step 5: บันทึกไฟล์

1. ตรวจสอบความเรียบร้อยของรายงานและตาราง
2. ตั้งชื่อไฟล์ใหม่: `OpsReport_ExecutiveSummary_<ชื่อผู้เรียน>.docx`


## Expected Output (สิ่งที่ควรได้)

- รายงานพร้อมส่งผู้บริหาร 1–2 หน้า
- มีตารางแผน 2 สัปดาห์ชัดเจน
- โทนเป็นทางการ แบบองค์กร
