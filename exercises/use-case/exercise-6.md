# Exercise 6 — Business Research ด้วย Researcher Agent 

## Step-by-step

1. เปิด Researcher Agent (ในประสบการณ์ที่องค์กรเปิดให้)
2. เลือกโจทย์วิจัย 1 ข้อ (จากด้านล่าง)
3. สั่งให้ agent สรุปเป็นรูปแบบ decision-ready
4. ขอให้ agent ระบุ “สิ่งที่ต้องตรวจสอบเพิ่มเติม” เพื่อความน่าเชื่อถือ

## โจทย์ตัวอย่าง (เลือก 1 ข้อ)

“แนวปฏิบัติที่ดีในการลด OT ของศูนย์กระจายสินค้าโดยไม่กระทบ OTIF”
“แนวทางปรับปรุงความปลอดภัยในคลัง (near-miss ลดลง) ที่ทำได้ใน 2 สัปดาห์”
“ตัวอย่าง KPI ที่ผู้บริหารใช้ติดตามประสิทธิภาพ DC และความพึงพอใจร้าน”

## Prompt Researcher Agent (Decision memo)

```
ช่วยทำสรุปแบบ Decision Memo 1 หน้า สำหรับผู้บริหาร CPALL เรื่อง: “แนวปฏิบัติที่ดีในการลด OT ของศูนย์กระจายสินค้าโดยไม่กระทบ OTIF”
ขอให้มี:

1. Options อย่างน้อย 3 ทางเลือก
2. Pros/Cons และผลกระทบต่อ KPI
3. ข้อเสนอแนะ (Recommended option)
4. สิ่งที่ต้องตรวจสอบเพิ่มเติม/ข้อจำกัด
```
