
# Copilot Work Mode 


## 1. ขั้นตอนการเข้าใช้งาน

1. เปิด link [https://m365copilot.com/](https://m365copilot.com/)
2. Login ด้วย Microsoft account ขององค์กร
3. เราจะเห็นเข้ามาที่ Copilot Chat ตามภาพ


![ภาพตัวอย่าง](../images/copilot/m365-copilot-chat.png)

## 2. เช็คก่อน เราใช้ Copilot แบบ free หรือแบบ license

- **สำหรับคนที่ใช้ Copilot แบบมี license** จะมีให้เลือกโหมด **Work | Web** 
- ซึ่งการใช้งานในส่วนนี้ **เราจะกดเลือกเป็นโหมด Work** 

![alt text](<../images/copilot/Screenshot 2568-08-22 at 00.18.40.png>)


> ถ้าเป็นแบบยังไม่ได้ซื้อ license จะไม่มีให้เลือกโหมด Work | Web นะครับ


## Feature 1: การถามถึงข้อมูลสำหรับการเปิดธุรกิจใหม่

1. เปิด link [https://m365copilot.com/](https://m365copilot.com/)
2. คัดลอกข้อความ prompt ด้านล่างไปใส่ในช่อง Chat 

ตัวอย่าง

```
สรุปหัวข้อการประชุมที่ต้องเตรียมจากไฟล์ /
```

3. เลือกไฟล์เอกสารที่เราได้อัพโหลดไว้ก่อนหน้า จาก onedrive โดยการพิมพ์ `/` ต่อจากข้อความ prompt 
   1. ใส่เป็นไฟล์ Business Idea.docx ที่เราได้อัพโหลดไว้ก่อนหน้า
4. กด enter หรือกดปุ่มส่ง (>)
5. ตรวจสอบผลลัพธ์ 


> เคล็ดลับ: ในที่นี้ถ้าเราสามารถอ้างอิงถึง meetings, บุคคลที่ติดต่อ (Contacts), หรือ Email และ Sharepoint ได้ด้วย

## ลองเล่น: ลอง prompt กับงานอื่นๆ ดูนะครับ

โหมด Work คือการที่ Copilot สามารถเข้าถึงข้อมูลใน Microsoft 365 ของเราได้ ทำให้เราสามารถใช้ Copilot ช่วยทำงานได้หลากหลายมากขึ้น 

และลองใช้ prompt ด้านล่างดูนะครับ

1. สรุปงานที่ต้องทำต่อกับผู้ติดต่อ (Contact) ที่เราสนใจโดยการค้นหา และเลือกจากรายชื่อผู้ติดต่อ (Contacts) ของเรา
```
สรุปงานที่ต้องทำต่อกับ /
```

2. สรุปความคืบหน้าของงานในสัปดาห์ที่แล้ว
```
สรุปความคืบหน้าของงานในสัปดาห์ที่แล้ว
```

3. ช่วยเตรียมการประชุมทั้งหมดในสัปดาห์นี้
```
ช่วยเตรียมการประชุมทั้งหมดในสัปดาห์นี้หน่อย
```
